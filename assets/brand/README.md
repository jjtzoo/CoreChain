# CoreChain logo system

This logo system is built around a longitudinal drill-core sample held inside a restrained `C` frame. The copper seam represents a visible geological feature continuing across separated core intervals.

## Files and uses

| Asset | Use |
| --- | --- |
| `corechain-primary-horizontal.png` | Default website header, reports, documents, presentations, sign-in screens |
| `corechain-stacked.png` | Centered or near-square layouts, title pages, event graphics |
| `corechain-symbol.png` | Compact navigation, product UI, social marks, favicon source |
| `corechain-wordmark.png` | Narrow layouts where the symbol is already established nearby |
| `corechain-primary-reversed.png` | Dark surfaces, dark mode, photography, video |
| `corechain-symbol-monochrome.png` | One-color printing, stamps, engraving, embroidery, Android themed icons |
| `corechain-app-icon-1024.png` | iOS/App Store master and general mobile app icon |
| `corechain-app-icon-512.png` | Android/Play Store and smaller distribution uses |
| `corechain-social-avatar-1080.png` | Social profile image and organization avatar |
| `corechain-favicon-64.png` | Browser favicon and very small web placements |
| `corechain-app-icon-master.png` | Original generated square source retained for future exports |

## Palette

- Graphite: `#182321`
- Warm limestone: `#EEEAE1`
- Muted copper: `#A66A43`

Use the horizontal logo by default. Use the standalone symbol only when the CoreChain name is already visible or the context is clearly branded. Keep clear space around every version and avoid adding shadows, gradients, outlines, or new colors.

These PNG assets were produced with the built-in image generation workflow from the approved CoreChain identity direction.

Matching SVG vector masters are included for the primary, reversed, stacked, symbol, wordmark, monochrome, and app-icon variants. The PNG exports are rendered from those masters for consistent geometry and clean transparent edges.
