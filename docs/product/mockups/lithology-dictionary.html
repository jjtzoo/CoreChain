Mockup · lithology dictionary and rock units

Every rock type in the project, and each hole as rock units

A dictionary of the project's lithologies, built from what was logged: how much of each, in which holes, at what depths, and its usual alteration and mineralisation. On each hole, touching intervals of the same rock merge into units, so 13 logged intervals read as 7 units. Data: the synthetic Cordillera porphyry project; every number here is calculated from its logs.

Rules

  • A unit is a run of touching intervals with the same lithology (or the same lithology and alteration type). A gap in the log, or an interval with no lithology, ends a unit. Nothing is changed in the log itself; units are a view.
  • Alteration and mineral figures are weighted by interval length. Intensity is shown as the length-weighted average, in words.
  • Rock groups (volcanic, intrusive, cover...) and descriptions come with the starter codes and can be edited in the code library. A code the team added has no group until someone sets one.
  • Everything is calculated on the phone from its own data, so it works with no signal and updates as soon as an interval is saved.
