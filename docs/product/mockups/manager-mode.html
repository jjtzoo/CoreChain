Where the 3D view lives

  • A tab on each project's page, next to Summary, Holes, Samples & lab and Progress report.
  • A "3D view" button on each project card on Today and in the Projects list, so it is one click from sign-in.
  • "See in 3D" on a hole's page and the project's hole list, opening the view on that hole (exists today).

Build order

  • 1. Top bar with six places; hole list moves to Holes; project cards on Today.
  • 2. Project page tabs: Summary, Holes, 3D view, Samples & lab.
  • 3. Samples & lab page: turnaround and the QA/QC held or rejected list.
  • 4. Progress report to print or save as PDF.
  • 5. Team page with phones and last sync.
  • All five are web only, from data already recorded: no migration, no new APK.
