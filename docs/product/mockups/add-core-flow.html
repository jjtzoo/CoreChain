Add core: enter the run once

Today one 3 m run of core is typed into four forms: the run, the box, the log interval and the sample. Each is a different measurement, but the depths are the same core. This flow asks for the run once and makes everything after it a tap.

Depths and rock names are real, from hole 200110-128 of the Alberta sample project (Alberta Geological Survey, AGS DIG 2024-0022). Box numbers, recovery and the split point are illustrative. Screens use the app's own dark theme.

How we will know it works

Depth values typed to take one 3 m run through box, log and sample:

4today, one per form,
with the new shortcuts
→
1target: the end of the run,
usually a chip

A design target, not a measurement. The app can count typed depths itself during the field test, so we will have the real number.

Principles it serves

  • P1Capture once. The start is inherited, the end is a chip, the split is a tap.
  • P3Thumb reach. Big chips and buttons, one hand, gloves on. No precision typing.
  • P5Errors at entry. Recovery over 100% or a gap between runs is flagged before saving, and can be dismissed with a reason.
  • P7Fast path first. Depth and rock only. RQD, notes and minerals are optional, one tap away.

Questions for the friendly geologist

  1. Is a run the right starting point? Or does the geologist think box first, because that is what is on the table?
  2. How often does geology change inside a run? If it is most runs, splitting on the strip must be very fast.
  3. Are the +1.5 / +3.0 / +6.0 chips the right run lengths? Rod length depends on the rig.
  4. Who does what? If a technician boxes and a geologist logs, the "What next" screen should show each person their own job.

What stays exactly as it is

  • The four forms remain, for anyone who prefers them or needs to correct one record.
  • Every record keeps its own depths, so editing a box never silently moves a log interval.
  • Everything works offline and syncs later; nothing here needs signal.
  • The gap, overlap and recovery warnings stay, and now appear before saving.
